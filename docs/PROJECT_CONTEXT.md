# Stubborn Ram

Версия документа: 0.1

Последнее обновление: июль 2026

---

# Назначение проекта

Stubborn Ram — это веб-платформа (PWA) для полного онлайн-сопровождения клиентов фитнес-тренера.

Проект создается как единая экосистема, которая объединяет все взаимодействие между тренером и клиентом в одном приложении.

Главная задача проекта — отказаться от использования большого количества отдельных сервисов (Telegram, PDF-файлы, Google Таблицы, Google Диск, заметки и т.д.) и предоставить клиенту единый удобный интерфейс.

Проект разрабатывается с расчетом на дальнейшее масштабирование.

---

# Миссия проекта

Сделать сопровождение клиента максимально удобным, понятным и современным.

Клиент не должен искать информацию в разных местах.

Всё должно находиться внутри платформы Stubborn Ram.

---

# Главная идея

Одно приложение.

Один аккаунт.

Вся работа происходит внутри платформы.

Клиент всегда имеет доступ к:

- своей программе тренировок;
- программе питания;
- рекомендациям;
- отчетам;
- истории прогресса;
- обратной связи тренера;
- уведомлениям.

---

# Цели проекта

Создать платформу, которая позволит:

- автоматизировать работу тренера;
- сделать сопровождение клиентов более удобным;
- сократить количество ручной работы;
- улучшить качество обратной связи;
- обеспечить постоянный доступ клиента к своим данным.

---

# Целевая аудитория

Основная аудитория:

- клиенты онлайн-тренера.

В дальнейшем платформа должна поддерживать работу нескольких тренеров.

---

# Принципы проекта

## Простота

Интерфейс должен быть максимально понятным.

Пользователь не должен задумываться, куда нажать.

---

## Минимализм

Минимум визуального шума.

Никаких лишних элементов.

Каждый элемент интерфейса должен выполнять полезную функцию.

---

## Mobile First

Проект в первую очередь создается для использования на смартфонах.

Версия для компьютера также поддерживается, но мобильный опыт является приоритетным.

---

## Масштабируемость

Архитектура проекта должна позволять добавлять новый функционал без полной переработки существующего кода.

---

## Скорость

Интерфейс должен работать быстро даже на не самых мощных устройствах.

Не использовать тяжелые решения без необходимости.

---

# Статус проекта

Проект находится в активной разработке.

Архитектура строится с расчетом на дальнейшее расширение функциональности.

Основная задача текущего этапа — создание надежного фундамента, который позволит постепенно добавлять новые возможности без ухудшения качества кода.
