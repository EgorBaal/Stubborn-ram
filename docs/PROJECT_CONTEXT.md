# Stubborn Ram

Версия документа: 0.2

Последнее обновление: июль 2026

---

# Назначение проекта

Stubborn Ram — это веб-платформа (с перспективой развития до полноценного PWA) для полного онлайн-сопровождения клиентов фитнес-тренера.

Проект создается как единая экосистема, объединяющая все взаимодействие между тренером и клиентом в одном приложении.

Главная задача проекта — отказаться от использования большого количества отдельных сервисов (Telegram, PDF-файлы, Google Таблицы, Google Диск, заметки и т.д.) и предоставить пользователю единый современный интерфейс.

Архитектура проекта изначально проектируется с расчетом на дальнейшее масштабирование.

---

# Миссия проекта

Сделать сопровождение клиента максимально удобным, понятным и современным.

Клиент не должен искать информацию в разных местах.

Всё взаимодействие должно происходить внутри платформы Stubborn Ram.

---

# Главная идея

Одно приложение.

Один аккаунт.

Одна экосистема.

Внутри платформы клиент всегда имеет доступ к:

- программе тренировок;
- программе питания;
- рекомендациям;
- отчетам;
- истории прогресса;
- обратной связи тренера;
- уведомлениям;
- своим персональным данным.

---

# Цели проекта

Создать платформу, которая позволит:

- автоматизировать работу тренера;
- сделать сопровождение клиентов удобнее;
- сократить количество ручной работы;
- ускорить обработку заявок;
- обеспечить постоянный доступ клиента ко всей необходимой информации;
- в будущем предоставить платформу другим тренерам.

---

# Целевая аудитория

Основная аудитория:

- клиенты онлайн-тренера.

Перспектива развития:

- независимые тренеры;
- небольшие фитнес-команды;
- фитнес-студии.

---

# Принципы проекта

## Простота

Интерфейс должен быть максимально понятным.

Пользователь не должен задумываться, куда нажать.

---

## Минимализм

Минимум визуального шума.

Каждый элемент выполняет конкретную задачу.

---

## Mobile First

Проект в первую очередь создается для использования на смартфонах.

Версия для компьютера также поддерживается, но мобильный опыт является приоритетным.

---

## Масштабируемость

Новый функционал должен добавляться без переписывания существующего проекта.

---

## Скорость

Интерфейс должен работать быстро даже на слабых устройствах.

Используются только действительно необходимые технологии.

# Текущее состояние проекта

На данный момент проект представляет собой полноценное веб-приложение с работающей серверной частью.

Полностью реализована следующая цепочка:

```
Пользователь

↓

Landing Page

↓

Анкета

↓

Supabase

↓

PostgreSQL

↓

Edge Function

↓

Resend

↓

Email тренеру
```

Проект доступен по собственному домену:

**stubbornram.ru**

Автоматическая публикация выполняется через GitHub Actions.
