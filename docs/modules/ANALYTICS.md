# ANALYTICS

## Назначение

Модуль ANALYTICS предназначен для отображения прогресса пользователя и агрегированной аналитики по ключевым доменам платформы.
В текущей ветке модуль существует как стартовая точка, но полноценная аналитическая подсистема еще не реализована.

## Статус

**PARTIALLY IMPLEMENTED** - маршрут и базовый экран есть, полноценный backend-driven analytics flow отсутствует.

## Текущая реализация

Подтверждено по коду:

- маршрут `/app/analytics` подключен в приложении;
- присутствует базовая страница `AnalyticsPage`;
- доступ к модулю выполняется через общий App Shell.

Пока не подтверждено:

- полноценная модель аналитических данных;
- dedicated backend API для аналитики;
- согласованный набор виджетов и бизнес-метрик.

## UI / Экраны

Текущий экран:

- `AnalyticsPage` (базовый экран).

Текущие характеристики:

- экран выполняет роль стартовой заглушки модуля;
- отсутствие полного сценария отображения аналитики.

## Текущий flow

1. Пользователь открывает `/app/analytics`.
2. Отображается базовый экран модуля.
3. Полный сценарий аналитики (фильтры, сравнительные периоды, агрегированные срезы) в текущем состоянии не завершен.

## Данные / Хранение

Текущее состояние:

- нет подтвержденного analytics-domain persistence в рамках отдельной подсистемы;
- нет подтвержденного единого backend-контракта аналитики.

## PARTIALLY IMPLEMENTED

- route и экран присутствуют;
- концепция модуля зафиксирована;
- end-to-end аналитический контур отсутствует.

## PLANNED

- единый набор аналитических блоков по модулям;
- сравнение периодов и трендов;
- связка с данными `Training`, `Food`, `Weight`, `PHOTO_AND_MEASUREMENTS`, `REPORT`;
- backend-driven выдача агрегированной аналитики.

## DEFERRED / NOT VERIFIED

- **DEFERRED**: расширенные визуализации и глубокие сравнительные срезы.
- **NOT VERIFIED**: production-ready analytics lifecycle.

## Известные ограничения

- текущая реализация носит базовый характер;
- отсутствует подтвержденный единый backend analytics contract;
- отсутствует полный пользовательский сценарий анализа прогресса.
