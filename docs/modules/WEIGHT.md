# WEIGHT

## Назначение

Модуль WEIGHT предназначен для отслеживания массы тела пользователя.
В текущей ветке модуль существует как экран-заглушка без подтверждённой модели хранения веса.

## Статус

**PARTIALLY IMPLEMENTED** — маршрут и UI-заглушка существуют, но рабочая история измерений и выделенный backend не подтверждены.

## Текущая реализация

Подтверждено по коду:

- маршрут `/app/weight` подключён в маршрутизатор;
- в `Home` есть карточка, ведущая в weight-раздел;
- `WeightPlaceholderPage` отображает заголовок и сообщение о разработке.

Не подтверждено:

- форма новой записи веса;
- история измерений;
- графики динамики;
- objective/personal plans;
- выделенный backend API и schema для weight module.

## UI / Экраны

Текущий экран:

- `WeightPlaceholderPage`.

Текущее содержимое:

- заголовок «Вес»;
- текст-заглушка «Раздел находится в разработке.».

## Текущий flow

1. Пользователь открывает `/app/weight`.
2. Отображается экран-заглушка.
3. Дальнейший сценарий ведения веса в текущей ветке отсутствует.

## Данные / Хранение

Текущее состояние:

- weight data не хранится в отдельной frontend-модели;
- выделенная persistence-модель веса в backend не обнаружена;
- таблицы или миграции для weight module не обнаружены.

## Backend

Проверка backend показала:

- выделенные маршруты weight не обнаружены;
- выделенные таблицы или миграции weight не обнаружены;
- выделенный service weight не обнаружен.

Важно:

- существующие упоминания `weight` в backend относятся к другим доменам, например `leads` и `training`, и не означают наличие отдельного weight module.

## Связь с Photo & Measurements

На уровне концепции weight связан с `PHOTO_AND_MEASUREMENTS`, но в текущей ветке:

- нет подтверждённой интеграции с фото или замерами;
- нет подтверждённой общей истории измерений, синхронизированной с photo module.

## PARTIALLY IMPLEMENTED

- маршрут есть;
- UI-заглушка есть;
- backend/persistence нет.

## PLANNED

- ввод и хранение измерений веса;
- история и динамика;
- связь с периодами и целями;
- интеграция с аналитикой и отчётами.

## DEFERRED / NOT VERIFIED

- **DEFERRED**: расширенная аналитика, графики и многоуровневая история.
- **NOT VERIFIED**: полный жизненный цикл weight и поведение в production.

## Известные ограничения

- модуль ограничен экраном-заглушкой;
- нет подтверждённого backend API;
- нет подтверждённой persistence-модели и истории.
