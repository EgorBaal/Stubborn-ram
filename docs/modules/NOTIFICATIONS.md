# БЛОК: УВЕДОМЛЕНИЯ

# Текущее состояние

На текущем этапе отдельный полноценный модуль уведомлений не реализован.

В коде уже существуют:

- `NotificationSection` на главном экране приложения;
- навигационные карточки к связанным разделам;
- базовая визуальная индикация уведомлений внутри Home.

Отдельного backend notification flow, центра уведомлений и push-механизма в текущем коде нет.

Полноценная реализация уведомлений остаётся отдельным будущим этапом.
