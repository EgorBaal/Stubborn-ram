# NOTIFICATIONS

## Назначение

Модуль NOTIFICATIONS предназначен для уведомления пользователя о событиях в платформе и перехода к связанным действиям.
В текущей ветке полноценный независимый модуль уведомлений еще не реализован.

## Статус

**PARTIALLY IMPLEMENTED** - есть интерфейсная заготовка уведомлений в Home, но отсутствует отдельная backend-driven notification subsystem.

## Текущая реализация

Подтверждено по коду:

- на главном экране используется `NotificationSection`;
- карточки уведомлений выполняют навигацию к связанным разделам;
- есть базовая визуальная индикация внутри Home.

Не подтверждено:

- отдельный центр уведомлений;
- полноценный backend notification flow;
- push-механизм и lifecycle прочтения уведомлений.

## UI / Экраны

Текущая поверхность:

- блок `NotificationSection` на Home.

Текущее поведение UI:

- уведомления представлены как статические карточки действий;
- переходы выполняются через навигационные ссылки на связанные модули.

## Текущий flow

1. Пользователь открывает Home.
2. Видит карточки уведомлений в `NotificationSection`.
3. Нажимает на карточку и переходит в связанный раздел.

## Данные / Хранение

Текущее состояние:

- отсутствует подтвержденный dedicated notification storage;
- состояние прочитано/непрочитано в рамках отдельного notification backend не подтверждено.

## PARTIALLY IMPLEMENTED

- UI-поверхность уведомлений есть;
- навигационная функция уведомлений работает на уровне Home;
- отдельного доменного модуля уведомлений пока нет.

## PLANNED

- единый notification-center;
- backend persistence уведомлений;
- read-state и жизненный цикл уведомлений;
- расширенные сценарии напоминаний и событийных сигналов.

## DEFERRED / NOT VERIFIED

- **DEFERRED**: push-инфраструктура и расширенная оркестрация уведомлений.
- **NOT VERIFIED**: production-ready notifications lifecycle.

## Известные ограничения

- текущая реализация ограничена секцией Home;
- отсутствует подтвержденный независимый backend для уведомлений;
- уведомления представлены главным образом как статический навигационный слой.
