==========================================
РАЗДЕЛ «ФОТО И ЗАМЕРЫ»
==========================================

ФИЛОСОФИЯ РАЗДЕЛА

Раздел «Фото и замеры» предназначен для объективного контроля изменения формы тела.

Раздел используется не ежедневно, а периодически:

• раз в неделю;
• раз в две недели;
• раз в месяц;
• либо по расписанию, назначенному тренером.

Основная единица раздела — не фотография и не замер.

Основная единица — КОНТРОЛЬНАЯ ТОЧКА.

Именно контрольная точка хранится в базе данных и используется аналитикой.

==========================================
КАЛЕНДАРЬ
==========================================

Календарь полностью повторяет архитектуру остальных разделов.

Дополнительно:

• дни, в которые была создана контрольная точка, отмечаются зеленой точкой под датой.

Это позволяет быстро увидеть:

• когда проводилась последняя контрольная точка;
• когда необходимо выполнить следующую.

При нажатии открывается контрольная точка выбранной даты.

==========================================
ЦЕЛЬ ПЕРИОДА
==========================================

Под календарем отображается текущая цель периода.

Например:

• Набор массы.
• Диета.
• Подготовка к соревнованиям.
• Поддержание формы.
• Восстановление.

Отображается:

• название периода;
• сроки действия (или бессрочно);
• кнопка «Подробнее».

При раскрытии отображаются:

• описание текущего этапа;
• комментарии;
• рекомендации;
• задачи данного периода.

Если тренера нет — пользователь управляет этим разделом самостоятельно.

Если тренер есть — цель периода назначается тренером.

==========================================
ПЛАН НА СЕГОДНЯ
==========================================

Карточка отображается только при наличии специальных задач на сегодняшний день.

Например:

• выполнить контрольную точку;
• сделать фотографии;
• выполнить дополнительные фотографии;
• выполнить дополнительные замеры;
• специальные комментарии тренера.

Карточка выделяется ярким цветом.

Если задач нет — карточка отсутствует.

==========================================
ПОСЛЕДНЯЯ КОНТРОЛЬНАЯ ТОЧКА
==========================================

Главная карточка раздела отображает:

• дату последней контрольной точки;
• количество фотографий;
• количество замеров;
• вес (автоматически подтягивается из раздела «Вес»);
• наличие комментария;
• наличие прикрепленного видео.

Из карточки можно перейти внутрь контрольной точки.

==========================================
СОЗДАНИЕ КОНТРОЛЬНОЙ ТОЧКИ
==========================================

При создании контрольной точки пользователь последовательно заполняет:

• Вес;
• Фото;
• Замеры;
• Видео (необязательно);
• Комментарий.

Контрольную точку можно заполнять постепенно.

Не требуется заполнение всех полей сразу.

Пользователь может:

• начать заполнение;
• выйти;
• позже вернуться;
• дополнить информацию.

Раздел не использует проценты заполнения и не принуждает пользователя завершать контрольную точку полностью.

==========================================
ВЕС
==========================================

Вес внутри контрольной точки вручную не вводится.

Он автоматически подтягивается из раздела «Вес».

Если сегодняшний вес уже существует:

• он автоматически отображается.

Если веса нет:

отображается сообщение:

"Сначала внесите сегодняшний вес в разделе «Вес»."

И кнопка перехода.

Вес не хранится повторно.

Используется ссылка на запись из раздела «Вес».

==========================================
ФОТОГРАФИИ
==========================================

Фотографии разделены на две категории.

------------------------------------------
1. БАЗОВЫЕ ФОТОГРАФИИ
------------------------------------------

Имеют фиксированные контейнеры.

Каждый контейнер имеет собственный постоянный внутренний ID.

Базовые позиции:

• Фронт расслаблен;
• Правый бок;
• Спина;
• Левый бок.

Каждая карточка содержит:

• название позы;
• силуэт-подсказку;
• кнопку прикрепления фотографии.

При нажатии пользователь выбирает фотографию именно для этой позиции.

Это позволяет автоматически сравнивать одинаковые позы между разными контрольными точками.

------------------------------------------
2. ДОПОЛНИТЕЛЬНЫЕ ФОТОГРАФИИ
------------------------------------------

При необходимости пользователь может добавить дополнительные контейнеры.

Например:

• Двойной бицепс спереди;
• Двойной бицепс сзади;
• Side Chest;
• Side Triceps;
• Пресс;
• Вакуум;
• Любые собственные позы.

Каждый дополнительный контейнер также имеет собственный внутренний ID.

==========================================
СТАНДАРТ СЪЕМКИ
==========================================

Под значком «ⓘ» отображается инструкция.

Например:

• одинаковый свет;
• одинаковое расстояние;
• одинаковая одежда;
• одинаковая поза;
• камера на одинаковой высоте;
• отсутствие пампа (при необходимости).

Это обеспечивает корректное сравнение фотографий между контрольными точками.

==========================================
СКРЫТИЕ ЛИЦА
==========================================

Для каждой фотографии доступна функция:

«Скрыть лицо».

После нажатия открывается простой встроенный редактор.

Пользователь может:

• включить скрытие лица;
• переместить область;
• изменить размер круга или овала;
• подтвердить.

После подтверждения лицо размывается.

Функция реализуется без использования ИИ.

Используется обычное размытие выбранной пользователем области.

==========================================
ВИДЕО
==========================================

К контрольной точке можно прикрепить одно дополнительное видео.

Видео является необязательным.

Основное назначение:

• позирование;
• демонстрация формы в движении;
• обязательные позы;
• оценка пластики.

Видео прикрепляется именно к контрольной точке и хранится вместе с ней.

==========================================
ЗАМЕРЫ
==========================================

Используется стандартный список замеров.

Например:

• Шея;
• Грудь;
• Талия;
• Таз;
• Бедро;
• Голень;
• Плечо;
• Предплечье.

Каждый замер имеет кнопку:

ⓘ

При нажатии отображаются:

• схема измерения;
• место измерения;
• рекомендации по правильному выполнению.

Пользователь самостоятельно выбирает необходимые замеры.

Если пользователь работает с тренером — список замеров назначает тренер.

Отображаются только выбранные показатели.

==========================================
КОММЕНТАРИЙ
==========================================

Каждая контрольная точка может содержать комментарий.

Например:

• завершение этапа;
• после болезни;
• после соревнований;
• особенности подготовки;
• любые дополнительные заметки пользователя или тренера.

==========================================
СРАВНЕНИЕ КОНТРОЛЬНЫХ ТОЧЕК
==========================================

Любую контрольную точку можно открыть в режиме:

«Сравнить».

Пользователь выбирает вторую контрольную точку.

После этого экран автоматически разделяется.

Отображаются:

• даты обеих контрольных точек;
• одинаковые фотографии напротив друг друга;
• одинаковые дополнительные фотографии;
• замеры напротив предыдущих значений;
• вес;
• комментарии.

Сравнение выполняется автоматически благодаря постоянным внутренним ID контейнеров фотографий и замеров.

Данный механизм в дальнейшем используется также в разделе «Аналитика».

==========================================
ТРЕНЕР И ПОЛЬЗОВАТЕЛЬ
==========================================

Без тренера:

Пользователь самостоятельно:

• создает контрольные точки;
• выбирает фотографии;
• выбирает замеры;
• пишет комментарии;
• управляет целью периода.

С тренером:

Тренер может:

• назначать контрольные точки;
• назначать обязательные фотографии;
• назначать замеры;
• писать комментарии;
• назначать задачи на конкретную контрольную точку.

Пользователь заполняет фактические данные.

Используется общий архитектурный принцип платформы:

Самостоятельный пользователь ↔ Пользователь с тренером.

==========================================
НАПОМИНАНИЯ
==========================================

Главная страница платформы может отображать уведомления.

Например:

• Сегодня запланирована контрольная точка.

• Последняя контрольная точка была 18 дней назад.

• Контрольная точка давно не выполнялась.

Напоминания помогают соблюдать регулярность контроля прогресса.

==========================================
АНАЛИТИКА
==========================================

Все данные автоматически сохраняются.

В дальнейшем аналитика получает доступ к:

• фотографиям;
• видео;
• замерам;
• весу;
• комментариям;
• датам контрольных точек.

Данные используются:

• для сравнения;
• построения графиков;
• анализа прогресса;
• формирования отчетов.

==========================================
АРХИТЕКТУРНЫЙ ПРИНЦИП
==========================================

Главным объектом раздела является Контрольная точка.

Контрольная точка содержит:

• дату;
• ссылку на вес;
• фотографии;
• дополнительные фотографии;
• видео;
• замеры;
• комментарий.

Все элементы привязаны к одной контрольной точке и используются совместно при сравнении и аналитике.

==========================================
АРХИТЕКТУРНЫЕ ТРЕБОВАНИЯ
==========================================

• Каждая контрольная точка имеет уникальный внутренний ID.

• Каждый контейнер фотографии имеет собственный постоянный внутренний ID.

• Каждый дополнительный контейнер фотографии также имеет собственный внутренний ID.

• Все замеры сохраняются с привязкой к контрольной точке.

• Вес не дублируется и используется по ссылке из раздела «Вес».

• Все данные бессрочно сохраняются в базе данных.

• Прошлые контрольные точки никогда автоматически не изменяются.

• Все данные доступны аналитике, отчетам и сравнению без создания дубликатов.

• Архитектура раздела должна оставаться расширяемой для добавления новых типов фотографий, замеров, видео и других параметров без изменения уже существующей структуры базы данных.
