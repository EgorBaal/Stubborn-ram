# Workflow разработки проекта Stubborn Ram

Назначение документа

Документ описывает единый процесс разработки проекта.

Все новые функции создаются по одному и тому же сценарию.

---

Этап 1. Идея

Новая идея сначала обсуждается в ChatGPT.

На этом этапе определяется:

- необходимость функции;
- логика работы;
- пользовательский сценарий;
- влияние на другие разделы.

---

Этап 2. Проектирование

После обсуждения создается архитектура функции.

Формируется "серая карточка", содержащая полное описание будущего раздела.

---

Этап 3. Документация

После утверждения карточка переносится в соответствующий файл:

docs/modules/...

Документация становится источником истины.

---

Этап 4. Реализация

После обновления документации задача передается Codex.

Codex обязан сначала изучить соответствующую документацию, а затем приступить к реализации.

---

Этап 5. Проверка

После реализации проверяется:

- соответствие документации;
- отсутствие ошибок;
- визуальное соответствие дизайн-системе.

---

Этап 6. Завершение

После завершения обновляются:

CHANGELOG.md

при необходимости:

PROJECT_CONTEXT.md

ARCHITECTURE.md

ROADMAP.md

DATABASE_SCHEMA.md
