# Приоритет разработки

Всегда соблюдать порядок:

1. Закончить текущий этап.

2. Только после этого начинать следующий.

3. Не оставлять незавершенные крупные модули.

---

# Главная цель MVP

После завершения первых этапов пользователь должен иметь возможность:

✔ зарегистрироваться;

✔ заполнить анкету;

✔ получить программу;

✔ отправлять отчеты;

✔ получать обратную связь;

✔ видеть историю своего прогресса.

После достижения этой цели MVP считается завершенным.
