# Приоритет разработки

Разработка ведется последовательно.

Основные правила:

1. Завершить текущий этап.
2. Не начинать несколько крупных модулей одновременно.
3. Не оставлять незавершенный функционал.
4. После завершения этапа обновить документацию.

---

# Цель MVP

Минимально жизнеспособная версия платформы должна позволять пользователю:

✔ зарегистрироваться;

✔ заполнить анкету;

✔ получить программу тренировок;

✔ получить план питания;

✔ отправлять отчеты;

✔ получать обратную связь тренера;

✔ просматривать историю прогресса.

После реализации этих функций MVP считается завершенным.

---

# После MVP

После завершения MVP развитие проекта продолжится в сторону полноценной платформы для нескольких тренеров.

Планируется:

- поддержка нескольких тренеров;
- расширенная аналитика;
- автоматизация сопровождения;
- новые интеграции;
- развитие мобильной версии;
- коммерческая эксплуатация платформы.
