# CHANGELOG.md

# Журнал изменений проекта Stubborn Ram

Данный документ содержит историю развития проекта.

Каждая завершенная версия фиксируется здесь.

Документ обновляется после завершения каждого крупного этапа разработки.

---

# Формат записей

Каждая версия содержит:

- дату;
- номер версии;
- список изменений;
- основные улучшения;
- технические изменения.

- ARCHITECTURE.md
- DESIGN_SYSTEM.md
- CODING_RULES.md
- ROADMAP.md
- CHANGELOG.md

- Mobile First.
- Один компонент = одна задача.

- Вынос логики из UI.
- Разделение данных, отображения и валидации.

# Версия 0.2

Дата:

июль 2026

Статус:

Интеграция серверной части и запуск первой рабочей версии.

### Реализовано

- Подключен Supabase.
- Настроена база данных PostgreSQL.
- Создана первоначальная структура базы данных PostgreSQL.
- Реализовано сохранение данных из анкет в базу данных.
- Создана Edge Function `send-lead-email`.
- Подключен сервис Resend.
- Реализована автоматическая отправка уведомления о новой заявке на электронную почту тренера.
- Настроены GitHub Secrets для безопасного хранения переменных окружения.
- Настроен GitHub Actions для автоматической сборки и публикации проекта.
- Куплен и подключен домен **stubbornram.ru**.
- Настроен GitHub Pages с использованием собственного домена.
- Исправлена конфигурация Vite после перехода на собственный домен.
- Исправлена работа React Router после перехода на собственный домен.
- Полностью протестирована цепочка:

```
Пользователь
      ↓
Заполнение анкеты
      ↓
Supabase
      ↓
Edge Function
      ↓
Resend
      ↓
Email тренеру
```

### Дополнительно

- Реализованы две полноценные анкеты сотрудничества.
- Реализована страница успешной отправки заявки.
- Полностью настроено взаимодействие фронтенда и серверной части.
- Проект переведен на рабочую инфраструктуру.

Следующим этапом разработки становится проектирование архитектуры базы данных, после чего начнется реализация системы авторизации и личных кабинетов.
