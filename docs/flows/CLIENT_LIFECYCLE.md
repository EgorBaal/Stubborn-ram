# Жизненный цикл клиента

На текущем этапе документ находится в разработке.

В проекте уже есть базовая структура приложения и маршруты для внутренних модулей, но полноценный сценарий жизненного цикла клиента еще не реализован.

Текущая реализация включает:

- базовый переход из лендинга в приложение;
- маршруты для основных разделов приложения;
- базовую авторизацию и защиту маршрутов.

Дальнейшая детализация жизненного цикла клиента будет выполняться по мере реализации модулей профиля, отчетов, тренировок и сопровождения.
