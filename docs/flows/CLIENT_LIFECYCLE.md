# CLIENT_LIFECYCLE

## Назначение

Документ описывает целевой и текущий жизненный цикл клиента в рамках платформы Stubborn Ram.
Он фиксирует пользовательский путь без дублирования детальной системной архитектуры.

## Статус

**PARTIALLY IMPLEMENTED** - базовый клиентский путь и маршруты существуют, полный lifecycle по всем модулям еще не завершен.

## Текущий клиентский контур

Подтверждено в текущем состоянии:

- переход из лендинга во внутреннюю часть приложения;
- базовая авторизация и защита приватных маршрутов;
- доступ к ключевым разделам через App Shell.

## Базовый сценарий клиента (CURRENT)

1. Пользователь приходит на публичную часть (landing).
2. Проходит регистрацию/вход.
3. Получает сессию и доступ к внутреннему приложению.
4. Переходит в основные разделы (Home и связанные модули).

## Расширенный сценарий клиента (PARTIALLY IMPLEMENTED)

- работа с тренировками и историей прогресса;
- взаимодействие с отчетами, комментариями и связанными разделами;
- использование профильных экранов и базовых действий аккаунта.

## PLANNED

- целостный lifecycle клиента по всем health-модулям;
- полная связка клиентских действий с доменными уведомлениями;
- завершенные сценарии аналитики, библиотеки и контентных циклов.

## DEFERRED / NOT VERIFIED

- **DEFERRED**: расширенные cross-module сценарии автоматизации клиента.
- **NOT VERIFIED**: полный production-ready lifecycle по всем целевым модулям.
