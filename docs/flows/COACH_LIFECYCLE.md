# COACH_LIFECYCLE

## Назначение

Документ фиксирует текущую и целевую логику жизненного цикла тренера в платформе Stubborn Ram.
Он описывает продуктовый поток действий тренера без подмены системных документов по архитектуре и правам.

## Статус

**PARTIALLY IMPLEMENTED** - базовый доступ и маршруты есть, полный coach lifecycle как независимая завершенная подсистема пока не реализован.

## Текущий контур тренера

Подтверждено в текущем состоянии:

- базовый вход во внутреннюю часть приложения через общую auth/session модель;
- доступ к существующим маршрутам и экранам в рамках текущего App Shell;
- наличие связанных модулей, часть которых остается на стадии placeholder/partial.

## Базовый сценарий тренера (CURRENT)

1. Пользователь с ролью/контекстом тренера проходит вход в систему.
2. Открывает внутренние разделы приложения.
3. Использует доступные на текущем этапе экранные сценарии.

## Расширенный сценарий тренера (PARTIALLY IMPLEMENTED)

- сопровождение клиентских процессов через доступные модули;
- участие в сценариях обратной связи и отчетных взаимодействий;
- использование профиля и связанных инструментов в пределах текущей реализации.

## PLANNED

- полноценный lifecycle сопровождения клиентов;
- завершенные coach-инструменты по работе с назначениями и обратной связью;
- сквозная интеграция с relationship/permissions-подсистемой на полном уровне.

## DEFERRED / NOT VERIFIED

- **DEFERRED**: расширенные coach workflows и автоматизации.
- **NOT VERIFIED**: полный production-ready lifecycle тренера по целевой модели.
