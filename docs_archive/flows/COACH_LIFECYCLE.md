# Жизненный цикл тренера

На текущем этапе документ находится в разработке.

В проекте уже есть базовая инфраструктура приложения и маршруты для внутренних модулей, но полноценный сценарий работы тренера еще не реализован.

Текущая реализация включает:

- базовый переход из лендинга в приложение;
- маршруты для основных разделов приложения;
- базовую авторизацию и защиту маршрутов.

Дальнейшая детализация жизненного цикла тренера будет выполняться по мере реализации модулей сопровождения, отчетов, чата и профиля.
