==========================================================
БЛОК: ГЛАВНЫЙ ЭКРАН ПРИЛОЖЕНИЯ (HOME)
Версия: 1.0 (Концепция)
==========================================================

Главный экран является центральной точкой входа в приложение.

Его задача — максимально быстро направить пользователя к нужному действию.

Главный экран НЕ является местом для просмотра подробной аналитики.

Главный экран — это навигационный центр всей платформы.

==========================================================

1. # ВЕРХНЯЯ ПАНЕЛЬ

В верхней части экрана располагаются:

• фирменный логотип Stubborn Ram;
• приветствие пользователя;
• кнопка уведомлений;
• аватар пользователя.

Логотип является частью интерфейса и присутствует на главном экране постоянно.

========================================================== 2. СТАТУСНЫЕ КАРТОЧКИ
==========================================================

Под верхней панелью располагаются 2–3 информационные карточки.

Они отображают только действительно важные события.

Например:

• новый комментарий тренера;
• новое сообщение;
• обновление программы;
• необходимо добавить вес;
• пришло время сформировать отчет;
• длительное отсутствие активности.

Карточки являются динамическими и меняются в зависимости от состояния пользователя.

Если пользователь занимается самостоятельно, отображаются только актуальные системные события.

Если пользователь работает с тренером, дополнительно появляются события, связанные с сопровождением.

========================================================== 3. ОСНОВНЫЕ РАЗДЕЛЫ ПРИЛОЖЕНИЯ
==========================================================

Под статусными карточками располагаются шесть крупных карточек.

Каждая карточка является входом в отдельный функциональный модуль приложения.

Карточки не отображают подробную информацию.

Их задача — быстро перевести пользователя в нужный раздел.

Основные разделы:

• Тренировка
• Питание
• Активность
• Отчет
• Фото и замеры
• Вес

========================================================== 4. ПРИНЦИП РАБОТЫ КАРТОЧЕК
==========================================================

Каждая карточка открывает полноценный раздел приложения.

Не используются всплывающие меню.

Пример:

Тренировка

↓

открывается экран "Тренировки"

↓

• начать тренировку;
• продолжить тренировку;
• программы;
• шаблоны;
• история тренировок;
• личные рекорды.

По такому же принципу работают все остальные разделы.

========================================================== 5. НИЖНЯЯ НАВИГАЦИЯ
==========================================================

Нижнее меню является постоянным элементом приложения.

Оно не изменяется при подключении тренера и остается одинаковым для всех пользователей.

Состав нижнего меню:

• Главная
• Библиотека
• Чат
• Аналитика
• Профиль

========================================================== 6. ЧАТ
==========================================================

Кнопка "Чат" присутствует всегда.

Если пользователь занимается самостоятельно:

• кнопка отображается неактивной.

После подключения тренера:

• кнопка становится активной;
• появляется доступ к переписке с тренером.

Структура нижнего меню при этом не изменяется.

========================================================== 7. ФИЛОСОФИЯ ГЛАВНОГО ЭКРАНА
==========================================================

Главный экран не предназначен для просмотра большого количества статистики.

Он отвечает только на один вопрос:

"Что пользователь хочет сделать прямо сейчас?"

Поэтому главный экран содержит:

• важные события;
• быстрый переход к основным разделам;
• минимальное количество отвлекающей информации.

========================================================== 8. ОСНОВНЫЕ ПРИНЦИПЫ UX
==========================================================

==========================================================
ИТОГ
==========================================================

Главный экран Stubborn Ram представляет собой центральный навигационный хаб приложения.

Все основные действия пользователя начинаются именно отсюда.

Каждая из шести карточек открывает самостоятельный функциональный модуль, а нижняя навигация обеспечивает быстрый доступ к ключевым разделам платформы.

Такая структура делает интерфейс простым, масштабируемым и одинаково удобным как для самостоятельного пользователя, так и для пользователя, работающего с тренером.
