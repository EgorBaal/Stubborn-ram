==========================================
РАЗДЕЛ «ВЕС»
==========================================

ФИЛОСОФИЯ РАЗДЕЛА

Раздел «Вес» предназначен для отслеживания динамики массы тела пользователя.

Его задача:

• фиксировать изменения массы тела;
• показывать общую динамику;
• помогать тренеру корректировать питание и тренировочный процесс;
• предоставлять достоверные данные для аналитики.

Раздел не пытается заменить функционал умных весов и не хранит второстепенные показатели (процент жира, мышечную массу, воду и т.д.). Основной показатель — масса тела.

==========================================
КАЛЕНДАРЬ
==========================================

• Любой день открывается нажатием.
• Каждый день представляет собой отдельную страницу.
• Структура страницы одинакова для сегодняшнего, вчерашнего или любого другого дня.
• Вся история реализована через календарь.

==========================================
ЦЕЛЬ ПЕРИОДА
==========================================

Под календарем отображается текущая цель периода.

Примеры:

• Набор массы.
• Снижение массы.
• Поддержание веса.
• Подготовка к соревнованиям.
• Восстановительный период.

Отображается:

• название периода;
• сроки действия (или бессрочно);
• кнопка «Подробнее».

При раскрытии отображается:

• описание текущего этапа;
• цель изменения массы;
• рекомендации по взвешиванию;
• комментарии тренера или пользователя.

Если тренера нет — пользователь полностью управляет этим разделом самостоятельно.

Если тренер есть — назначение периода выполняет тренер.

==========================================
ПЛАН НА СЕГОДНЯ
==========================================

Карточка отображается только тогда, когда на конкретный день существуют отдельные назначения.

Например:

• контрольное взвешивание утром натощак;
• ожидаемый диапазон массы;
• комментарий после читмила;
• рекомендации после перелета;
• рекомендации после загрузки углеводами;
• любые другие индивидуальные указания.

Карточка выделяется более ярким цветом и располагается сразу под целью периода.

При отсутствии индивидуальных назначений карточка не отображается.

==========================================
ТЕКУЩИЙ ВЕС
==========================================

Главная карточка раздела.

Отображается:

• текущий основной вес;
• изменение относительно предыдущего основного измерения;
• расстояние до цели периода;
• средний вес за последние 7 дней;
• ссылка «Новая запись».

Пример:

Вес

101.4 кг

↓ -0.4 кг с прошлого измерения

До цели: 2.6 кг

Средний за 7 дней: 101.9 кг

Новая запись

Если установлен новый минимум или максимум за выбранный период, отображается отметка:

🏆 Новый минимум

или

🏆 Новый максимум

==========================================
НОВАЯ ЗАПИСЬ
==========================================

При нажатии «Новая запись» открывается нижняя карточка.

Поля:

• вес;
• тип измерения;
• комментарий (необязательно).

Тип измерения:

• Утром натощак (по умолчанию);
• После еды;
• После тренировки;
• После читмила;
• Вечером;
• Другое.

Комментарий используется только при необходимости.

Например:

• После перелета.
• После загрузки.
• После соревнований.
• После болезни.
• Любая пользовательская заметка.

==========================================
МИНИ-ГРАФИК
==========================================

Под карточкой веса отображается небольшой график изменения массы тела.

По умолчанию отображается динамика за последние 30 дней.

При нажатии открывается полный график.

Полная аналитика располагается в разделе «Аналитика».

==========================================
ИСТОРИЯ ИЗМЕРЕНИЙ
==========================================

Под мини-графиком располагается раскрывающаяся история измерений.

Отображается в текстовом виде:

Дата — Вес

Например:

Сегодня      101.4 кг

Вчера        101.8 кг

29 апреля    101.6 кг

28 апреля    101.9 кг

Если внутри дня имеются дополнительные измерения или комментарии, рядом отображается значок заметки.

При нажатии открывается вся информация выбранного дня.

==========================================
НЕСКОЛЬКО ИЗМЕРЕНИЙ ЗА ДЕНЬ
==========================================

В течение одного календарного дня пользователь может выполнить неограниченное количество измерений.

Например:

• утром натощак;
• после тренировки;
• после еды;
• после читмила;
• вечером.

Все измерения сохраняются внутри одного календарного дня.

При открытии дня отображаются:

• время измерения;
• вес;
• тип измерения;
• комментарий (если существует).

==========================================
ТРЕНЕР И ПОЛЬЗОВАТЕЛЬ
==========================================

Без тренера:

Пользователь самостоятельно:

• назначает цель периода;
• устанавливает целевые значения;
• добавляет комментарии;
• ведет дневник веса.

С тренером:

Все назначения выполняет тренер.

Пользователь может:

• просматривать назначения;
• выполнять измерения;
• добавлять фактический вес;
• добавлять комментарии к своим измерениям.

Редактирование назначений пользователем недоступно.

Во всем разделе используется единый архитектурный принцип платформы:

Самостоятельный пользователь ↔ Пользователь с тренером.

==========================================
АНАЛИТИКА
==========================================

Все измерения автоматически сохраняются и используются аналитикой.

В дальнейшем отображаются:

• график изменения массы тела;
• средний вес за выбранный период;
• динамика набора;
• динамика снижения;
• изменение относительно цели;
• сравнение периодов;
• связь с питанием;
• связь с активностью;
• связь с фотографиями;
• связь с замерами.

==========================================
УВЕДОМЛЕНИЯ
==========================================

Раздел веса интегрируется с системой уведомлений главного экрана.

Примеры:

• Сегодня необходимо выполнить контрольное взвешивание.

• Вес сегодня еще не внесен.

• Достигнут новый минимум массы.

• Цель периода достигнута.

==========================================
АРХИТЕКТУРНЫЙ ПРИНЦИП
==========================================

Каждый календарный день может содержать неограниченное количество измерений веса.

Основным измерением автоматически считается первое измерение с типом:

«Утром натощак».

Именно оно используется:

• на главном экране;
• в мини-графике;
• в аналитике;
• в отчетах;
• при расчете средней массы тела;
• во всех сводных показателях.

Если в течение дня пользователь добавляет дополнительные измерения (после еды, после тренировки, после читмила и т.д.), они сохраняются внутри этого же дня и не заменяют основное измерение.

Если измерение «Утром натощак» отсутствует, основным автоматически становится первое измерение, добавленное в этот день.

==========================================
АРХИТЕКТУРНЫЕ ТРЕБОВАНИЯ
==========================================

• Каждое измерение веса имеет внутренний уникальный ID.

• Каждый календарный день также имеет собственный внутренний ID.

• Один день может содержать неограниченное количество измерений.

• Все измерения сохраняются в базе данных бессрочно.

• Прошлые записи никогда не изменяются автоматически.

• Все данные доступны аналитике без создания дубликатов.

• Структура раздела проектируется как расширяемая.

На первом этапе используются только:

• вес;
• тип измерения;
• комментарий.

Архитектура должна позволять в будущем без изменения структуры базы добавить дополнительные параметры измерения, если это потребуется.

Все изменения должны быть обратно совместимы с уже существующими данными.
