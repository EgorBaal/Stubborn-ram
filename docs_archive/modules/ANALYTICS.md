# Текущее состояние

На текущем этапе полноценный модуль аналитики находится в разработке.

В коде уже существуют:

- маршрут `/app/analytics`;
- базовая страница `AnalyticsPage`;
- доступ через общий App Shell приложения.

Текущая реализация является placeholder-экраном и не содержит полноценной бизнес-логики аналитики.

Дальнейшая детализация модуля выполняется отдельным этапом roadmap.
