## 2. Данные в таблицах

Через `pg_class` подтверждено наличие 16 таблиц. Однако роль `stubbornram_app` **не может** выполнять SELECT к данным из-за отсутствия прав (ACL = null, таблицы принадлежат `postgres`).

При попытке чтения данных:
- `SELECT count(*) FROM pgmigrations` → ERROR 42501 (permission denied)
- `SELECT count(*) FROM users` → ERROR 42501 (permission denied)

Это ожидаемое поведение при восстановлении с `--no-owner --no-privileges` от имени `postgres`. Объекты принадлежат `postgres`, а `stubbornram_app` не имеет явных разрешений на чтение.

## 6. Найденная проблема: права доступа в stubbornram_test

После восстановления с `--no-owner --no-privileges` от имени `postgres`:
- Все 16 таблиц принадлежат `postgres`
- ACL = null (нет явных разрешений)
- `stubbornram_app` не может читать данные (ERROR 42501)
- `stubbornram_app` может подключаться к БД и видеть структуру через `pg_class`

Это не ошибка восстановления — объекты созданы корректно. Но для полноценной проверки восстановления приложением потребуется `GRANT` прав.

**Не исправлено намеренно:** изменения прав в тестовой базе выходят за рамки текущего этапа.
